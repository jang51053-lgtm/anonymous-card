# 익명 카드로 알아가기

아이들이 익명 이름과 캐릭터 그림으로 카드를 만들고, 교생 쌤이 카드를 미리 읽은 뒤 대화로 "이 카드는 누구일까?" 찾아가는 교실용 웹앱입니다. 단일 `index.html` + Firebase Firestore로 동작합니다. **로그인 없이 코드만 입력**하면 들어갑니다.

## 입장 방식
- 시작 화면에 **코드 하나**만 입력하면 학생 / 교생 쌤 / 담임이 자동으로 구분됩니다.
- 담임이 `새 학급 만들기`에서 **담임 코드 · 교생 코드 · 학생 코드** 세 개를 정합니다. (설정 탭에서 언제든 변경)
- 학생은 코드 입력 후 **내 번호**를 고르고, 교생 쌤은 **이름**만 적습니다.

## 활동 순서
1. 담임: 새 학급 만들기 → 설정에서 명단(번호 이름) 등록 → 학생 코드 안내 (단계: 카드 만드는 중)
2. 학생: 카드 제출
3. 담임: 단계를 **마감**으로 전환 → 교생 쌤이 열람 (교생 코드 안내)
4. 담임: 정답 공개 (단계 전환 또는 "카드 한 장씩 뒤집기")
5. 실습이 끝나면 설정 탭에서 **전체 삭제**

## 알아 둘 점
- 교생 쌤 화면에는 실명·번호가 나오지 않습니다. 정답 공개 단계에서만 실명이 전달됩니다.
- 코드로 역할을 구분하므로, 코드를 아는 사람은 해당 역할로 들어올 수 있습니다. 담임 코드는 알려 주지 마세요.
- 이 앱의 데이터는 Firestore의 `anoncls`, `anoncodes` 컬렉션에 저장됩니다.
- 저장소의 `firestore.rules`는 이전 로그인 방식용 초안이며, 현재 버전에서는 사용하지 않습니다.
