# 익명 카드로 알아가기

교생 쌤을 맞이하기 전에, 아이들이 익명 이름과 캐릭터 그림으로 카드를 만들고 교생 쌤이 카드를 미리 읽은 뒤 대화로 "이 카드는 누구일까?" 찾아가는 교실용 웹앱입니다. 단일 `index.html` + Firebase(Firestore, Authentication)로 동작합니다.

## 역할
- **학생**: 학급 코드 + 번호 + 숫자 6자리 비밀번호로 입장 → 카드 만들기(익명 이름, 그림판, 꿈, 고민, 단서)
- **교생 쌤**: 구글 로그인(담임이 이메일 등록) → 마감 후 익명 카드 열람, 추측 메모, 관찰 노트
- **담임**: 구글 로그인 → 명단·교생 등록, 단계 전환, 고민 원문, 정답 공개

## 설정 순서
1. Firebase 콘솔에서 프로젝트를 만들고 **Firestore Database**(프로덕션 모드, 서울 `asia-northeast3` 추천)를 만든다.
2. **Authentication → 로그인 방법**에서 `Google`, `이메일/비밀번호`를 켠다.
3. **Authentication → 설정 → 승인된 도메인**에 `<아이디>.github.io`를 추가한다.
4. **프로젝트 설정 → 내 앱 → 웹 앱**을 만들고 `firebaseConfig` 값을 `index.html` 위쪽 `firebaseConfig`에 붙여 넣는다.
5. **Firestore → 규칙**에 `firestore.rules` 내용을 붙여 넣고 **게시**한다.
6. 담임이 앱에서 `담임 쌤` → 구글 로그인 → 새 학급 코드를 만든 뒤 명단, 교생 이메일을 등록한다.

## 활동 순서
1. 담임: 학급 코드와 명단 등록 → 학생에게 코드 안내 (단계: 카드 만드는 중)
2. 학생: 카드 제출
3. 담임: 단계를 **마감**으로 전환 → 교생 쌤이 열람
4. 담임: 정답 공개 (단계 전환 또는 "카드 한 장씩 뒤집기")
5. 실습이 끝나면 설정 탭에서 **전체 삭제**

## 알아 둘 점
- 교생 쌤 화면에는 실명·번호가 나오지 않습니다. 정답 공개 단계에서만 실명이 전달됩니다.
- 학생이 비밀번호를 잊으면 담임이 "고민 원문" 탭에서 해당 번호를 초기화하면 새로 시작할 수 있습니다(카드 내용은 삭제됨).
- 교생 쌤의 노트는 본인만 볼 수 있고, "담임에게 공유"를 켠 것만 담임이 볼 수 있습니다.
